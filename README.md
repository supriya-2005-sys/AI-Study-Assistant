## 📌 Project Overview

AI Study Assistant is a simple Machine Learning-based chatbot developed using Python and Streamlit.

It is designed to help students understand basic computer science concepts by answering study-related questions through an interactive chatbot interface.

The chatbot uses TF-IDF vectorization and Cosine Similarity to match user questions with predefined questions and provide relevant answers.

## 🎯 Project Objectives

- Help students understand basic computer science concepts.
- Provide quick answers to study-related questions.
- Create an interactive and user-friendly chatbot.
- Learn practical applications of Machine Learning and NLP.
- Develop a project using Python libraries.

## ✨ Key Features

- Interactive chatbot interface.
- Predefined study-related questions and answers.
- Suggested questions for quick learning.
- Question similarity matching.
- Chat history management.
- Clear Chat functionality.
- Simple and user-friendly design.

## 🛠️ Technologies Used

| Technology | Description |
|---|---|
| Python | Main programming language |
| Streamlit | Web application interface |
| Scikit-learn | Machine Learning library |
| TF-IDF | Text vectorization |
| Cosine Similarity | Text similarity matching |

## 📚 Topics Covered

The chatbot provides answers related to:

- Python Programming
- SQL
- Database Management System (DBMS)
- Artificial Intelligence
- Machine Learning
- HTML, CSS and JavaScript
- APIs
- Data Structures
- Computer Networks

## ⚙️ How the Chatbot Works

1. The user enters a question in the chatbot.
2. The question is converted into numerical features using TF-IDF.
3. Cosine Similarity compares the user's question with predefined questions.
4. The chatbot identifies the most similar question.
5. The corresponding predefined answer is displayed.

## 💻 Installation and Setup

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project Folder

```bash
cd AI_STUDY_ASSISTANT
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
streamlit run app.py
```

The chatbot will open in your web browser at:

`http://localhost:8501`
